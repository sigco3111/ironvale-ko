Mouse
Left clickSelect unit / building. Shift+click adds or removes.
Left dragBox-select your units
Double clickSelect all your units of that type on screen

WheelZoom in / out
Middle dragRotate camera
MinimapClick / drag to move the camera; right click to send selected units
Keyboard
WASD / ArrowsPan camera (also screen edges)
Q / ERotate camera
CAMERA panelDrag the round dial to rotate and tilt; hold + / − to zoom; Close / Normal / Far / Top / Map presets
Alt + dragOrbit the camera with the left mouse button (or drag with the middle button)
WheelZooms toward the mouse pointer
PageUp / PageDownTilt camera (also Shift+wheel)
+ / −Zoom — zoom all the way out to see the whole map
MWhole-map overview on / off (VIEW → MAP); TOP = top-down view

Esc / PCancel placement / Pause menu
